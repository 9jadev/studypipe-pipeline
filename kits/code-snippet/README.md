# StudyCode Kit (`code-snippet`)

The **StudyCode** kit provides offline, high-performance syntax highlighting, step-by-step execution tracing, and line-by-line pedagogical explanations for Nigerian Computer Studies and programming lessons.

## What it provides:
- **Offline Syntax Highlighting**: Lightweight tokenizer for Python, BASIC, Pseudocode, and JavaScript without any external CDNs or heavy runtimes.
- **Line Explainer Notes (`.code-step-note`)**: Each line can have a clear, student-friendly note explaining what happens on that exact line.
- **Step Execution Tracer**: Interactive controls (Step Forward, Step Back, Reset) with active line highlights and a dynamic Variable Watch panel.
- **Terminal Console Box**: Displays simulated shell/command-line input and output.
- **One-Click Copy**: Copies clean code to clipboard with visual confirmation feedback.

## Files
- `code-kit.js`: Standalone script exposing `window.StudyCode`.
- `code.css`: Responsive stylesheet with dark terminal look, tokens, and mobile optimizations.
- `demo.html`: Verification demo.
