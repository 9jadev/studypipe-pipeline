The Unit Mystery · Ikogosi, Ekiti State

The Ikogosi Smart Solar Microgrid Shutdown

In Ikogosi, Ekiti State, an automated community solar microgrid distributes power to the cottage hospital, the cold-chain vaccine store, and 250 households. At 18:00 during an evening rainstorm, the backup diesel generator fails to start despite batteries dropping below 15%, the vaccine refrigerator locks in an error loop (Error 0x7E: Array Index Out of Range), and the billing terminal charges ₦15,020 instead of ₦170 for a 20-unit top-up.

Chief Babatunde fears the expensive inverter bank is fried and wants to dismantle it. Amina and Tari hook up their maintenance laptop to Engr. Idris’s diagnostic port and discover the hardware is undamaged—every fault lies inside the control software.

How do high-level code instructions become machine voltage pulses, and how can systematic debugging save the microgrid?

  • Clue 1 · Data TypesSensor reading "150" was stored as text, so "150" + 20 joined into "15020" instead of 170.
  • Clue 2 · Boolean LogicThe generator relay checked battery < 20 and grid_online instead of battery < 20 and not grid_online.
  • Clue 3 · Runaway LoopA while loop monitoring solar irradiance omitted the counter increment, freezing microcontroller memory.
  • Clue 4 · Array BoundsThe battery scanner looped from index 0 to 8 on an 8-cell rack whose valid indices are 0..7.

Realism note: modern solar microgrids, hybrid inverters, and telecom base stations across Nigeria run embedded microcontrollers programmed in C/C++ or MicroPython using these exact sequential, conditional, loop, array, and modular function structures.

Language Abstraction Ladder

Lesson 1: High-Level Python → Assembly Mnemonics → 8-bit Binary Machine Code

Core rule
Hardware only executes binary (0 and 1); translators bridge the gap
How it works
Compiler: whole program at once. Interpreter: line by line at runtime
Exam point
Machine code needs no translator; assembly uses an assembler

Humans think in formulas like energy = units * 68.0, whereas the CPU ALU only switches transistors on (1) and off (0). A compiler or interpreter parses high-level tokens and emits exact machine instructions.

The 6 calculation archetypes

Almost every numerical and trace question in WAEC, NECO, and JAMB programming falls into one of these six patterns. Each step has a plain-English note underneath.

Type 1 · Lesson 1

Operator precedence, floor division & modulus

  1. R = 12 + 8 × 2 − 6 ÷ 2 = 12 + 16 − 3 = 25Multiplication and division execute before addition and subtraction.
  2. 19 // 4 = 4, 19 % 4 = 3Integer floor division // drops the decimal; modulus % keeps the remainder (19 = 4 × 4 + 3).
Type 2 · Lesson 1

Data type casting & VAT billing

  1. total = int("150") + 20 = 150 + 20 = 170 kWhCasting "150" with int() converts text digits into a whole number before adding.
  2. bill = 85 × 68 × 1.075 = 5780 × 1.075 = ₦6213.5085 units at ₦68 per kWh gives ₦5,780; multiplying by 1.075 adds the 7.5% VAT.
Type 3 · Lesson 2

Compound boolean truth evaluation

  1. P = (18 < 20) = True, Q = NOT(False) = TrueBattery is 18% (< 20 is True) and grid_online is False, so NOT grid_online is True.
  2. start_gen = P AND Q = True AND True = TrueAn AND gate outputs True only when both input conditions are True simultaneously.
Type 4 · Lesson 3

Loop counter & accumulator sum

  1. range(1, 6) → i in {1, 2, 3, 4, 5}In Python, range(start, stop) includes start (1) and stops strictly before stop (6).
  2. sum = 1 + 2 + 3 + 4 + 5 = 15The accumulator starts at 0 and adds each counter value i on every pass.
Type 5 · Lesson 4

Zero-based array index & memory offset

  1. i_max = N − 1 = 8 − 1 = 7An 8-element array spans indices 0 to 7; index 8 is out of bounds.
  2. Addr(i) = Base + i × S = 1000 + 3 × 4 = 1012With 4-byte elements starting at address 1000, index 3 lives at byte 1012.
Type 6 · Lessons 5 & 6

Function return, hex & binary decoding

  1. F = (9/5)C + 32 = 1.8(37.0) + 32 = 98.6 °FThe function computes F in local scope and returns 98.6 to the caller.
  2. 0x7E = (7 × 16) + 14 = 126₁₀ = 01111110₂Hex 7 is 0111₂ and hex E (14) is 1110₂, forming the 8-bit register byte 01111110₂.
