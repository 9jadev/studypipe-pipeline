Practical analysis questions

Answer these two analysis questions from your bench trace, then compare with the model answers.

  1. Why did the accumulator total_kwh (or sum) increase monotonically with each iteration step, and why must it be initialized to 0 before the loop starts?
  2. In the while count < 5 test, what statement was missing inside the loop body, and why did the watchdog timer have to interrupt execution?
Model answers unlocks after you try
  1. Each iteration executes total = total + reading, adding the positive daily kWh value onto the previous running sum (45 → 97 → 157 → … → 382 kWh). Initializing total = 0 outside the loop provides the additive identity; if initialized inside the loop, it would reset to zero on every pass.
  2. The increment statement count = count + 1 (or count += 1) was missing. Because count stayed fixed below 5, the condition count < 5 evaluated to True forever, creating an infinite loop that required an emergency hardware watchdog interrupt.
3Make sense · 15 min

Iteration, Counters, Accumulators & Loop Termination

Connect your 3D stepper traces to the formal programming definitions, flowchart back-edges, and Python vs BASIC loop syntax tested in WAEC, NECO, and JAMB.

Core looping vocabulary

Iteration is the automated repetition of a block of instructions until a specified condition is met. A Counter is a variable (such as i or count) that tracks the number of times a loop has executed, stepping by a fixed increment. An Accumulator is a variable (initialized to 0 for sums or 1 for products before the loop) that collects a running total across iterations: total = total + value.

Sentinel Values & Infinite Loops: In a condition-controlled WHILE loop where the count is not known in advance, a sentinel value (such as typing -1 or "QUIT") is a special input marker that signals the end of data entry. An infinite loop occurs when the termination condition never evaluates to False (for example, forgetting to increment the counter variable inside a while loop). Inside any loop, break exits the entire loop immediately, whereas continue skips only the remainder of the current iteration and jumps to the next cycle test.

EXAMPLE 3.1

Accumulating 7-day solar power output & daily average

The Ikogosi solar array logs 7 daily generation values in kilowatt-hours: daily_readings = [45, 52, 60, 58, 49, 63, 55]. Write and trace a Python program that accumulates the 7-day total and computes the average daily generation rounded to 2 decimal places.

daily_readings = [45, 52, 60, 58, 49, 63, 55] total_kwh = 0 for reading in daily_readings: total_kwh += reading average_kwh = total_kwh / len(daily_readings) print("Total Generation: " + str(total_kwh) + " kWh") print("Average Generation: " + str(round(average_kwh, 2)) + " kWh")
  1. Initialize accumulator outside the loop: set total_kwh = 0 so prior memory values cannot corrupt the sum.
  2. Accumulate across all 7 iterations:
    Accumulator & Mean Calculation LaTeX · 2 Steps
    1 Step 1 Running Total
    💡Each pass adds one day's reading: 45 → 97 → 157 → 215 → 264 → 327 → 382 kWh.
    2 Step 2 Final Answer
    💡Divide the final sum after the loop exits by len(daily_readings) (7 days) and round to 2 decimal places.

EXAMPLE 3.2

Countdown loop for diesel backup generator warm-up timer

Before the backup diesel generator transfers load at night, its glow-plug controller counts down from 5 seconds to 1 second and then prints "Generator Ready". Trace both the negative-step FOR loop and the equivalent WHILE loop.

for k in range(5, 0, -1): print("Warm-up:", k, "s") print("Final k =", k, "· Generator Ready")
  1. Start, stop, and negative step: range(5, 0, -1) begins at 5 and adds -1 on each cycle while k > 0.
  2. Generated sequence: 5, 4, 3, 2, 1 (5 iterations). Zero is the exclusive stop boundary and is never assigned to k.
  3. Equivalent WHILE countdown: initialize sec = 5, test while sec > 0:, and include sec -= 1 inside the loop body so sec reaches 0 and terminates cleanly.
Sequence = 5, 4, 3, 2, 1 (5 iterations) · Final value of k after loop = 1

b3. Explain what an infinite loop is, give code demonstrating one, and show how to fix it.

4 marks
Solution unlocks after you try

An infinite loop is a loop whose exit condition is never satisfied (never becomes False), causing it to repeat endlessly without terminating (1).
Infinite loop example: x = 1; while x <= 5: print(x) (1).
Fixed code: Increment the control variable inside the loop body: x = 1; while x <= 5: print(x); x += 1 (2).

b5. Explain the difference between break and continue statements inside a loop.

4 marks
Solution unlocks after you try

break terminates the entire enclosing loop immediately and transfers execution to the statement directly after the loop (2). continue skips only the remaining statements in the current iteration and jumps directly back to the next iteration test (2).

b8. Why must the accumulator variable be initialized outside the loop rather than inside?

3 marks
Solution unlocks after you try

If initialized inside the loop body, the accumulator resets to zero on every single iteration, erasing the running total from previous steps and leaving only the value of the final iteration (3).
