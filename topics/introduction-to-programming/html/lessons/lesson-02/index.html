1. Relational & Logical Operators

Relational operators compare two values and return a boolean result (True or False). Logical operators (and, or, not) combine or invert boolean values. In operator precedence, relational comparisons run first, then not, then and, and finally or.

!=Not equal tox != 20True

Branching structures & flowchart diamonds: A flowchart decision point is drawn as a Diamond (Rhombus) with at least two mutually exclusive labeled exit arrows (True/False or Yes/No). In a multi-way if-elif-else ladder, Python checks conditions top-to-bottom: once the first matching branch executes, all remaining elif and else blocks are skipped!

EXAMPLE 2.1

ATM Cash Withdrawal Validation (Multi-way if-elif-else)

An ATM holds a customer's account_balance = 25000 (₦25,000), requested_amount = 10000 (₦10,000), and daily_limit = 20000 (₦20,000). Trace the validation branches and compute the remaining balance.

account_balance = 25000 requested_amount = 10000 daily_limit = 20000 if requested_amount > account_balance: print("Error: Insufficient funds.") elif requested_amount > daily_limit: print("Error: Exceeds daily withdrawal limit.") else: account_balance -= requested_amount print("Dispensing N" + str(requested_amount)) print("Remaining Balance: N" + str(account_balance))
First if condition compares requested amount against account balance; since ₦10,000 is not greater than ₦25,000, this branch is skipped.
The elif condition checks the daily limit; since ₦10,000 does not exceed ₦20,000, this branch is also skipped.
The else block executes, deducting ₦10,000 to leave a final balance of ₦15,000.
  1. Check funds (line 5): 10000 > 25000 is False, so the insufficient-funds branch is skipped.
  2. Check daily limit (line 7): 10000 > 20000 is False, so the daily-limit branch is skipped.
  3. Execute else branch (lines 9–12): account_balance = 25000 - 10000 = 15000; prints Dispensing N10000 and Remaining Balance: N15000.
Dispensing N10000 · Remaining Balance: N15000
EXAMPLE 2.2

NEPA / Disco Electricity Band Tariff Selection

An electricity distribution company classifies feeders into tariff bands based on daily supply hours (hours_per_day): Band A (>= 20 hrs), Band B (>= 16 hrs), Band C (>= 12 hrs), and Band D (< 12 hrs). Trace the output when hours_per_day = 18.

hours_per_day = 18 if hours_per_day >= 20: band = "Band A (Premium 20+ hrs)" elif hours_per_day >= 16: band = "Band B (Standard 16-19 hrs)" elif hours_per_day >= 12: band = "Band C (Basic 12-15 hrs)" else: band = "Band D (Lifeline <12 hrs)" print("Tariff Category: " + band)
  1. Test Band A (line 3): 18 >= 20 evaluates to False.
  2. Test Band B (line 5): 18 >= 16 evaluates to True, so band = "Band B (Standard 16-19 hrs)" is assigned.
  3. Mutual exclusion (lines 7–10): Even though 18 >= 12 is also true, Python skips all remaining elif and else branches once the first match succeeds.
Tariff Category: Band B (Standard 16-19 hrs)

Part B · 30-Mark Written Examination Paper

b1. Distinguish between single-alternative (IF), dual-alternative (IF-ELSE), and multiple-alternative (IF-ELIF-ELSE) branching structures.

4 marks
Solution unlocks after you try

Single-alternative executes a code block only if a condition is true, doing nothing otherwise (1). Dual-alternative provides two mutually exclusive paths: one for true, another for false (1). Multiple-alternative tests a sequence of conditions in order until one matches, with an optional catch-all else (2).

b2. Construct a complete truth table for the logical expression: Y = A AND (NOT B).

4 marks
Solution unlocks after you try

Row 1: A=0, B=0, NOT B=1 → Y = 0 AND 1 = 0 (1).
Row 2: A=0, B=1, NOT B=0 → Y = 0 AND 0 = 0 (1).
Row 3: A=1, B=0, NOT B=1 → Y = 1 AND 1 = 1 (1).
Row 4: A=1, B=1, NOT B=0 → Y = 1 AND 0 = 0 (1).

b6. What is short-circuit evaluation in boolean expressions? Illustrate with False and (x / 0 == 1).

4 marks
Solution unlocks after you try

Short-circuit evaluation occurs when a programming language evaluates a compound boolean expression from left to right and stops as soon as the final truth outcome is guaranteed (2). In False and (x / 0 == 1), because the first operand is False, the AND expression must be False; the second operand x / 0 is never evaluated, preventing a division-by-zero runtime crash (2).

b7. Differentiate between relational operators and logical operators, giving two examples of each.

3 marks
Solution unlocks after you try

Relational operators compare two values (e.g., >, ==, <=) to produce a boolean truth value (1.5). Logical operators combine or invert boolean truth values (e.g., AND, OR, NOT) (1.5).

b8. Why must nested if statements be indented properly in modern languages like Python?

3 marks
Solution unlocks after you try

In Python, indentation defines code block scope and hierarchy rather than curly braces (1.5). Incorrect indentation causes an IndentationError or a logic bug where statements execute under the wrong condition (1.5).
