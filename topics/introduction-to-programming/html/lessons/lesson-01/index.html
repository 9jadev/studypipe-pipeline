1. Programs, Source Code & Language Generations

A computer program is a sequence of logical instructions written to direct a computer to perform a specific task. Computer programming is the process of designing, writing, testing, debugging, and maintaining those instructions.

  • Machine Language (1st Generation · Low-Level): Written in raw binary digits (0s and 1s representing low and high transistor voltages). It is the only language directly executed by the CPU without any translation, but it is hardware-dependent and tedious for humans.
  • Assembly Language (2nd Generation · Low-Level): Uses short symbolic mnemonics such as MOV, ADD, and SUB. It requires a translator called an Assembler to convert mnemonics into machine code.
  • High-Level Languages (3rd Generation & above): Use human-readable English keywords and mathematical notation (e.g. Python, BASIC, Java, C++). They are portable across machines and require a Compiler or Interpreter to translate source code into machine code.

2. Compiler vs. Interpreter Comparison

FeatureCompilerInterpreter
Translation InputTranslates the entire source program at once before executionTranslates and executes source code line-by-line at runtime
Output FileGenerates a standalone object / executable file (e.g. .exe)Does not save standalone object code; needs source file every run
Execution SpeedFaster runtime execution (already compiled to native binary)Slower runtime execution (translates every line while running)
Error DetectionScans the whole file and reports all syntax errors together after compilationHalts immediately at the very first syntax or runtime error encountered
Example LanguagesC, C++, Rust, Go, FortranPython, BASIC, JavaScript, Ruby

3. Data Types, Variables, Constants & Naming Rules

A variable is a named memory location in RAM whose stored value can change during program execution. A constant is an immutable named value that remains fixed throughout execution (such as VAT_RATE = 0.075).

Data TypePython KeywordMeaning & ExamplesTypical RAM Role
IntegerintWhole positive or negative numbers without decimals: 230, -15, 0Counters, array indices, whole kWh units
Floating-PointfloatReal numbers containing a decimal point: 68.5, 220.75, 0.15Tariff rates, voltages, temperatures
StringstrSequence of text characters enclosed in quotes: "Ikogosi", "150"Names, meter serial numbers, messages
BooleanboolLogical truth value: True or False (case-sensitive in Python)Sensor flags, relay switch states

Three Golden Rules for Valid Variable Identifiers (WAEC / JAMB):
1. Must begin with a letter (a–z, A–Z) or an underscore (_) — never a digit (_student_age is valid; 2nd_score is invalid).
2. Must not contain spaces or arithmetic hyphens (use total_bill, never total bill or total-bill).
3. Must not be a reserved keyword of the language (such as class, for, if, def, return).

EXAMPLE 1.1

Airtime recharge bonus script in Python & BASIC

A telecom promo awards a 15% airtime bonus on a ₦1,000 recharge. Trace the Python and BASIC programs to find bonus_amount and total_credit.

recharge = 1000 bonus_rate = 0.15 bonus_amount = recharge * bonus_rate total_credit = recharge + bonus_amount print("Total Airtime: N" + str(total_credit))
REM Airtime Recharge Bonus in BASIC LET RECHARGE = 1000 LET BONUSRATE = 0.15 LET BONUSAMOUNT = RECHARGE * BONUSRATE LET TOTALCREDIT = RECHARGE + BONUSAMOUNT PRINT "Total Airtime: N"; TOTALCREDIT END
  1. Multiply the ₦1,000 recharge by the 0.15 decimal bonus rate to obtain a ₦150 bonus.
  2. Add the ₦150 bonus to the ₦1,000 base recharge to get a total airtime credit of ₦1,150.
bonus_amount = ₦150.00 · total_credit = ₦1,150.00
EXAMPLE 1.2

Type conversion & NEPA electricity billing with 7.5% VAT

A smart meter transmits units_str = "85". Convert this string to an integer, multiply by the tariff rate of ₦68 per kWh, and compute the total bill including 7.5% Value Added Tax (VAT).

units_str = "85" units = int(units_str) tariff = 68 energy_cost = units * tariff vat = energy_cost * 0.075 total_bill = energy_cost + vat print("Energy: N" + str(energy_cost) + " | VAT (7.5%): N" + str(vat) + " | Total Bill: N" + str(total_bill))
  1. Cast the raw meter string "85" to the integer 85 so arithmetic multiplication is valid.
  2. Multiply 85 kWh by ₦68 per unit to find the base energy charge of ₦5,780.
  3. Multiply ₦5,780 by the 7.5% VAT rate (0.075) to get ₦433.50.
  4. Add the base energy cost and VAT to obtain the final electricity bill of ₦6,213.50.
energy_cost = ₦5,780.00 · VAT (7.5%) = ₦433.50 · total_bill = ₦6,213.50
EXAMPLE 1.3

Floor division, modulus & operator precedence

(a) Find the integer quotient and remainder when 19 solar panels are grouped into strings of 4 using 19 // 4 and 19 % 4. (b) Evaluate result = 12 + 8 * 2 - 6 / 2.

  1. Floor division // drops the .75 decimal to leave 4 full groups; modulus % gives the 3 remaining panels.
  2. Following operator precedence, evaluate multiplication (8 * 2 = 16) and division (6 / 2 = 3.0) before addition and subtraction to get 25.0.

Explain the exact difference between writing x = 5 and x = "5" in Python, and state what x + x produces in each case.

2 marks
Model answer unlocks after you try

x = 5 assigns the numeric integer 5 to x, so x + x performs arithmetic addition and evaluates to 10 (1). x = "5" assigns a one-character string literal to x, so x + x performs string concatenation and evaluates to "55" (1).

Part B · 30-Mark Written Examination Paper

b1. Define computer programming (1) and distinguish between source code (1) and object code (2).

4 marks
Solution unlocks after you try

Computer programming is the process of designing, writing, testing, and maintaining instructions for a computer to execute (1). Source code is human-readable code written in a high-level or assembly language (1). Object code is machine-readable binary code generated after translation by a compiler or assembler (2).

b2. State three major differences between a compiler and an interpreter.

4 marks
Solution unlocks after you try

(1) A compiler translates the entire source code into machine code in one batch before execution, whereas an interpreter translates and executes instructions line-by-line (2).
(2) A compiler produces an independent executable object file (.exe), whereas an interpreter does not save object code and requires the source code on every run (1).
(3) A compiler lists all syntax errors at the end of compilation, whereas an interpreter halts immediately at the first error encountered (1).

b6. Explain what a type mismatch error is and demonstrate how to resolve it when adding cost = "4500" and vat = 337.5.

4 marks
Solution unlocks after you try

A type mismatch error occurs when an operation is attempted on incompatible data types, such as attempting to add a text string and a numeric float (2). It is resolved by casting the string to a numeric float or integer before adding: total = float(cost) + vat (evaluating to 4837.5) (2).
