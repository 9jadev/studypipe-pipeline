1. Binary (Base-2) & Hexadecimal (Base-16)

Inside silicon chips, every number and instruction is stored in binary (base-2) using bits (0 for 0 V LOW, 1 for 3.3 V HIGH). An 8-bit group forms one byte with positional weights 128, 64, 32, 16, 8, 4, 2, 1.

Long strings of 1s and 0s are hard for humans to read, so engineers group every 4 bits (one nibble) into a single hexadecimal (base-16) digit using 0–9 and A–F (where A=10, B=11, C=12, D=13, E=14, F=15). Hexadecimal is used everywhere for memory addresses (0x00FF), status codes (0x7E), and web RGB color codes (#04AA6D = Red 04, Green AA, Blue 6D).

0x7E = 0111 1110₂  ·  (7 × 16¹) + (14 × 16⁰) = 126₁₀  (7 = 0111₂, E = 14 = 1110₂)

Split any 2-digit hex byte into two 4-bit nibbles for instant binary conversion, or multiply the left digit by 16 and add the right digit (0–15) to obtain decimal.

2. The 3 Classes of Bugs & WAEC Marking Rubric

Error ClassWhen CaughtTypical Causes & Examples
Syntax ErrorBefore execution (parse / compile time)Violates language grammar: missing colon (if x > 5), unmatched bracket, misspelled keyword (whle).
Run-Time ErrorMid-execution (program crashes)Legal grammar, illegal operation: ZeroDivisionError (10/0), IndexError (cells[8]), TypeError ("150"+20).
Logic ErrorRuns to completion with wrong outputFlawed reasoning: score > 70 instead of >= 70, missing loop counter update, wrong boolean gate (and grid_online).

WAEC Chief Examiner Marking Scheme: When grading programming and trace-table questions, examiners award separate method marks for (1) variable initialization before the loop, (2) exact loop conditions & indentation, (3) one chronological row per iteration showing intermediate variable changes, and (4) the final output line.

Converting 0x4A to Binary & Decimal + In-Place Variable Swap

(a) Convert hexadecimal telemetry byte 0x4A into 8-bit binary and decimal. (b) Trace the classic no-temp variable swap for a = 4 and b = 3.

a = 4 b = 3 a = a + b b = a - b a = a - b print("a:", a, "b:", b)

Expand each hexadecimal digit into a 4-bit binary nibble (remember A = 10 = 8 + 2).

Join the upper nibble 0100 and lower nibble 1010 to form the 8-bit binary byte.

Multiply the left hex digit by 16 and add the right digit (10) to obtain decimal 74.

Using additive arithmetic swaps a and b in place without allocating a temporary third variable.

2 marks
Model answer unlocks after you try

b1. Differentiate clearly between syntax errors, run-time errors, and logic errors, providing one concrete example of each.

4 marks
Solution unlocks after you try

Syntax error: violation of language grammatical rules detected before or during translation (e.g. prnt("Hi") or missing colon) (1.5).
Run-time error: occurs during execution causing abrupt termination (e.g. dividing by zero 10 / 0 or accessing an out-of-bounds array index) (1.5).
Logic error: program runs to completion without crashing, but produces incorrect output due to faulty reasoning (e.g. using + instead of *) (1).
