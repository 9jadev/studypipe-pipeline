Formal definitions

An array (implemented as a dynamic list in Python) is an ordered collection of data elements stored in contiguous (adjoining) memory locations under a single identifier. Each individual item stored in the collection is called an element, and its position number inside square brackets [i] is called its index (or subscript).

Zero-Based Indexing & the Offset Model: in C, Java, JavaScript, and Python, an index is not a human counting number — it is the offset (number of element steps) from the array's starting Base Address. Because the first element sits right at the base address, its offset is 0. For an array of length , valid positive indices run from to .

·
📐Calculation & Formula Guide: Multiply the 0-based index i by the element byte size and add to the base address to jump directly to any slot in O(1) constant time. Valid positive indices run from 0 to N − 1.

At index 0 (1st element), the byte offset is zero, pointing directly to the array's base address 0x1000.

At index 3 (4th element, holding 2.95 V), the CPU adds 3 × 4 = 12 bytes to jump straight to 0x100C in O(1) constant time.

The 8th and final element sits at index 7 (0x101C..0x101F); asking for index 8 (0x1020) steps past the 32-byte boundary and raises IndexError.

EXAMPLE 4.1

Finding the lowest battery cell voltage in an array

The 8-cell lithium rack at the Ikogosi Clinic records voltages cells = [3.25, 3.18, 3.30, 2.95, 3.22, 3.15, 3.28, 3.20]. Write and trace a Python program that finds the lowest voltage and prints both its 1-based physical cell number and voltage.

cells = [3.25, 3.18, 3.30, 2.95, 3.22, 3.15, 3.28, 3.20] min_voltage = cells[0] min_index = 0 for i in range(len(cells)): if cells[i] < min_voltage: min_voltage = cells[i] min_index = i print("Weakest Cell: Cell " + str(min_index + 1)) print("Voltage: " + str(min_voltage) + " V")
  1. Seed with first element: set min_voltage = cells[0] = 3.25 and min_index = 0. (If we seeded min_voltage = 0, no positive cell voltage would ever be smaller!)
  2. Iteration i = 1: cells[1] = 3.18 < 3.25 is True → min_voltage = 3.18, min_index = 1.
  3. Iteration i = 2: cells[2] = 3.30 < 3.18 is False → unchanged.
  4. Iteration i = 3: cells[3] = 2.95 < 3.18 is True → min_voltage = 2.95, min_index = 3.
  5. Iterations i = 4..7: values 3.22, 3.15, 3.28, 3.20 are all ≥ 2.95, so min_voltage stays 2.95 at min_index = 3.

Adding 1 converts the 0-based machine index (3) into the technician's 1-based physical slot number (Cell 4).

Weakest Cell = Cell 4 (index 3, address 0x100C) · Minimum Voltage = 2.95 V
EXAMPLE 4.2

Indexing and averaging student test marks

Given marks = [70, 80, 90, 100]: (a) find marks[1] + marks[3], and (b) trace a loop to compute the class average of all four scores.

marks = [70, 80, 90, 100] print("Pair sum:", marks[1] + marks[3]) total = 0 for m in marks: total += m average = total / len(marks) print("Average mark:", average)
  1. Identify indexed elements: marks[0] = 70, marks[1] = 80, marks[2] = 90, marks[3] = 100.
  2. Evaluate pair sum: marks[1] + marks[3] = 80 + 100 = 180. (Similarly, for JAMB MCQ 5 with [65, 80, 45, 90], marks[1] + marks[3] = 80 + 90 = 170.)
  3. Accumulate and divide: total = 70 + 80 + 90 + 100 = 340, and len(marks) = 4.

Dividing the accumulated sum (340) by the list length (4) yields a floating-point mean of 85.0.

marks[1] + marks[3] = 180 · Total = 340 · Average = 85.0

b3. Explain what an off-by-one error is and identify the error in this code:
cells = [3.2, 3.3, 3.1, 3.4]
for i in range(1, 5): print(cells[i])

4 marks
Solution unlocks after you try

An off-by-one error occurs when an iterative loop executes one time too many or one time too few due to incorrect boundary conditions (2). In this code, range(1, 5) starts at index 1 (skipping cells[0]) and attempts to access cells[4], which is out of range for a 4-item list (valid indices 0..3), raising an IndexError (2).

b6. Differentiate between a one-dimensional array and a two-dimensional array, giving an everyday example of each.
